# FlowRead

Иммерсивный ридер для epub-книг с RSVP (Rapid Serial Visual Presentation) и режимом фокусированного чтения.

## Возможности

- **RSVP-режим** — слова показываются по одному с центрированием на оптимальной точке фиксации (ORP)
- **Режим «Страница»** — полный текст с подсветкой текущего слова
- **Умные паузы** — напоминания моргать, смотреть вдаль, пить воду каждые 1000 слов
- **Библиотека** — загруженные книги сохраняются в браузере (IndexedDB)
- **Прогресс** — запоминает позицию в каждой главе, при возврате начинает с предыдущего предложения
- **Навигация** — назад/вперёд по предложениям, при возврате автоматически включает режим «Страница» для контекста
- **Адаптивная скорость** — пауза на знаках препинания, длинных словах, концах абзацев

## Запуск

Один HTML-файл, без бэкенда. Открыть `index.html` в браузере.

Для тестирования на телефоне (в той же WiFi-сети):

```bash
python3 -m http.server 8000
# На телефоне: http://<ip-компьютера>:8000
```

## Клавиатура

| Клавиша | Действие |
|---------|----------|
| Space | Пауза / Продолжить |
| ← | Назад на предложение |
| → | Вперёд на предложение |
| ↑ / ↓ | Скорость ±25 WPM |
| M / Tab | Переключить режим |

## Стек
